Aide et assistance DrazonChat

DrazonChat est un bot Discord qui traduit la discussion dans la langue de votre interlocuteur. Il ne traduit que les messages des personnes qui l'ont activé elles-mêmes, et il traduit aussi le texte des images.

Bien démarrer

Un administrateur du serveur ajoute le bot depuis le serveur d'assistance. Ensuite, chaque personne qui veut être traduite lance /traduire activer sur ce serveur. Le bot devine votre langue et celle de votre interlocuteur, puis ouvre le panneau de réglages ; corrigez-les dans les menus déroulants si elles ne sont pas justes. Écrivez comme d'habitude : la traduction s'affiche sous votre nom.

Commandes courantes

CommandeFonction
/traduire activerActive la traduction automatique de vos messages sur ce serveur. La première fois, il devine votre langue et celle de votre interlocuteur, puis ouvre le panneau de réglages
/traduire configurerPanneau de réglages : choisissez votre langue, celle de votre interlocuteur et le ton, et activez ou désactivez la traduction
/traduire desactiverDésactive la traduction automatique
/traduire utilisationAffiche les traductions utilisées ce mois-ci et celles qu'il vous reste
/traduire supprimer-mes-donneesSupprime les données que le bot conserve sur vous
/traduire aideAffiche les commandes, les dernières nouveautés et les liens vers le serveur d'assistance et la politique de confidentialité
Clic droit sur un message → Applications → TraduireLire le message de quelqu'un d'autre dans votre langue (vous seul le voyez)
Clic droit sur un message avec des images → Applications → TraduireAffiche [Traduire le texte] et [Placer sur l'image]. Traduisez le texte des images, ou recevez une copie où le texte d'origine est effacé et la traduction dessinée à sa place (vous seul la voyez)
Icônes sous les images d'une personne qui a activé la traduction automatiqueL'icône de page traduit le texte, l'icône d'image place la traduction sur l'image. Tout le monde peut appuyer dessus ; le résultat et le décompte reviennent à la personne qui a appuyé
Menu déroulant des polices sous une image avec la traduction dessinéeChoisissez Standard, BD, Manuscrite ou Titre gras, et l'image est redessinée sans rien décompter
Clic droit sur un message → Applications → Supprimer ma traductionSupprime l'un de vos messages traduits

Si votre Discord est réglé sur une autre langue, les noms des commandes s'affichent dans cette langue.

La traduction sur l'image fonctionne le mieux sur les captures d'écran, les mèmes, les écrans de jeu, les panneaux et les menus. Le texte vertical est dessiné verticalement (les lettres latines, comme en anglais, sont tournées pour suivre la colonne). Le thaï et l'hindi ne peuvent pas encore être placés sur les images.

Les mises à jour et les formules sont publiées dans les salons des nouveautés et des formules du serveur d'assistance.

Si une traduction semble fausse, envoyez une capture d'écran du message et indiquez-nous les deux langues concernées. Le contenu des discussions n'est pas conservé dans les journaux du bot, votre capture d'écran est donc ce qui aide le plus.

Supprimer vos données

  • Dans Discord, tapez /traduire supprimer-mes-donnees et appuyez sur le bouton de confirmation dans les 10 minutes. Les données sont supprimées immédiatement.
  • Un message traduit dans un salon peut être supprimé à tout moment : clic droit dessus → Applications → « Supprimer ma traduction ».
  • Si vous ne pouvez pas le faire vous-même, faites la demande via l'assistance ci-dessus et l'opérateur le supprimera.

Formules

Le bot est en phase pilote et n'accepte pas encore de paiements. Une fois les paiements ouverts, vous pourrez changer ou résilier votre formule sur la page des formules de ce site. Le bot n'envoie jamais de liens de paiement.

Confidentialité

Ce qui est conservé, combien de temps, et où les messages sont envoyés pour être traduits : tout est dans la politique de confidentialité.
