1. What the service is

Cozirom is a Discord bot that translates chat into the other person's language. It translates only the messages of people who turned translation on themselves, and it stops as soon as they turn it off. The exception is a channel where a server admin turned on language channels: every message there is translated (section 3).

(Chrome extension) Cozirom for Web is a Chrome extension that translates text on web pages, browser games and inside images. It translates through a web translation server (api.cozirom.com) operated separately from the Discord bot; the extension holds no translation-provider API key. It translates only the tabs and sites where you turned translation on (section 3). Until the extension's Discord sign-in opens, it is used only in the operator's testing. The use of information received from the Chrome extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

3. What is sent out for translation

Translation is done with the Claude API of Anthropic PBC (United States). Voice message transcription and the voices for voice-channel reading are done with the Gemini API (paid tier) of Google LLC (United States). We send:

  • Auto-translation: the message text, the writer's Discord display name (and username if different), and up to 6 recent messages from the same channel within the last 15 minutes written by users who turned auto-translation on (3 on the Free plan, 600 characters in total) with their display names. If the message contains words or names from your glossary, those entries (both cells) are sent too. The "My name" lines (display name and chosen spelling) of people who use the bot in that server are sent too, only when that name appears in the message.
  • Translation rooms: in a private thread the bot made (a room), only the messages of people who pressed [Join] are sent. What is sent is the same as for auto-translation (the message text, the writer's name, recent messages from people who joined the same room within the last 15 minutes with their writers' names, and glossary entries; the number of context messages follows the plan of whoever pays for that translation). Messages are translated in the languages and tone set in the room, not by the writer's own auto-translation settings. The messages of people who haven't joined (people who were only invited, server admins who can see the room without joining, people pulled in by a mention) are not translated, not sent and not used as context, even if they turned auto-translation on (requests other people press, such as right-click translation, work as in "Requests from other people" below). Messages left as they are because the room is paused (the server turned rooms off, or the room owner left the server or changed plans) or because the room owner's friend share is used up are not sent either.
  • Server plans: in servers with a server plan, server glossary entries (both cells) are sent too when their words appear in a message (if your own glossary has the same word, yours comes first for your messages). When a server admin turns on language channels for a channel, all of people's messages in that channel are sent to be copied into the languages turned on, even if they haven't turned auto-translation on (what is sent is the same as for auto-translation; nothing is sent from age-restricted channels or for messages starting with //). If a message is edited after it was copied, the edited text is sent again. If the writer has auto-translation on, the copy in that translation's language reuses the auto-translation and nothing extra is sent.
  • Right-click translation and /translate once: the message you picked (or typed), its writer's name, and the same-channel context before it (same rule as above). The glossary used is the writer's entries and name line (same rule as above, including the name line of the person who pressed).
  • Text in images: if you press [Translate text] on the right-click translation screen or on the image icons of a translated message, the images in that message (up to 10, copies shrunk to 1,568 px on the long side) are sent to read their text, then the text read and its writer's name are sent for translation. If you press [Put on image] on the right-click translation screen, on the image icons or under the text translation result, the bot finds where the text is, sends a small copy of the image together with the text areas cut out of it in one request to read the text, and translates it (for an image with a lot of text you see the cost first, and once you confirm, the cut-out text areas are sent as one sheet per 16 text blocks, up to 8; finding, erasing and drawing happen on the bot's computer, and the image with the translation is shown only to you). The bot doesn't store the images. The text read is kept only in memory briefly for redrawing (section 2) and, if the image has 200 characters of text or less in all, in the translation cache so the same image isn't paid for twice (the text read with its corrected original, the names in the image, and the translation; section 2). Nothing is sent until you press it.
  • File translation (applies once file translation opens): if you press [Translate file] on the right-click translation screen, the bot downloads that message's TXT or PDF file (up to 1 MB for TXT, 20 MB for PDF), extracts its text, and sends that text (up to 100,000 characters per file, for PDFs up to your plan's number of pages, and up to 300,000 characters in all per person per day) in paragraphs for translation. The language is chosen as in right-click translation: a file written in your language goes into your other language, and any other file into your language, as shown on the offer (estimated from the beginning of the file on the bot's computer; nothing is sent for this). Pages that are only an image are turned into a picture (1,568 px on the long side) and sent like image text reading to read their text (up to 30 pages per file), and the text read is translated with the other paragraphs. A new file is made from the translation and shown only to you. The bot doesn't store the file, the extracted text, the text read from image-only pages or the translated file, and doesn't put them in the translation cache. Nothing is sent before you press the button (to show the page and character counts on the offer, the file is read in advance only on the bot's computer). Files in age-restricted channels aren't translated.
  • Voice messages: if someone on a paid plan presses [Transcribe and translate] on the right-click translation screen in an age-restricted channel, the audio file of that voice message (up to 3 minutes) is sent to Google's Gemini API to be transcribed, then the transcript and its writer's name are sent to Anthropic for translation. In other channels, in DMs and on the free plan, nothing is transcribed or sent. The bot doesn't store the audio or the transcript (translations follow the translation cache rule). Nothing is sent until you press it, and that screen names where the audio goes.
  • View in another language: when someone who can see a translated message presses 🔎 and picks [View in another language], the original stored by the bot (within 14 days, up to 1,500 characters), the writer's glossary entries and the name line of the person who pressed are sent to Anthropic to be translated into the chosen language. This works regardless of the writer's settings, and only for translated messages whose original record still exists; the writer can stop it by deleting the original record with "Delete my translation".
  • Meaning explanations: the text of the message you picked (for a message Cozirom translated and posted, the stored original you can see with the 🔎 button), its writer's name, and the same-channel context before it (same rule as above). The explanation is not stored and only you see it. How many you used each month is kept with your plan records (section 2).
  • Voice-channel reading: in age-restricted voice channels of servers where an admin turned voice-channel reading on, the translations of what people on a paid plan who picked a voice themselves write in that voice channel's chat (up to 200 characters, without links and mentions) are sent to Google's Gemini API to be read aloud in the voice they picked. The screen where you pick a voice names where it is sent, and messages of people who haven't picked a voice, people on the free plan and people not in that voice channel are not sent. [Listen to a preview] sends only a fixed sample sentence. The text read and the audio are not stored (only the short phrases the bot has fixed and the sample sentence of [Listen to a preview] are kept in memory as audio, not linked to any person).
  • (Chrome extension) Page translation: the visible text of a tab where you turned translation on (icon or shortcut), or of a site set to translate automatically next time. Input fields, password fields, editable areas and code blocks are never sent. Also sent: the site's domain (never the full URL or search terms), the page title, a few previously translated lines, the matching site-glossary entries, and your chosen language and tone. Numbers are replaced with placeholders and filled back in on the page.
  • (Chrome extension) Keep translation on: while [Keep translation on] is switched on in the popup, the same kind of text as above is sent for every page you open. Pages already in your language, pages with a password field or a payment field such as a card number (sign-in and payment screens), small frames such as ads, and sites you excluded are not sent, and if such a field appears after the page has opened, no new text is sent while it is there. Turning the switch off stops it.
  • (Chrome extension) Files on your computer: if you turn on [Allow access to file URLs] for Cozirom in Chrome's extension settings and turn translation on in an HTML file on your computer (such as a downloaded game), the same text as in "Page translation" above is sent. Instead of a site domain, "file." followed by a short irreversible hash of the file name (or, if the file is named index.html, of the name of the folder it is in), made with a random value unique to this installation (a 32-byte salt kept only in your browser), is sent as the site name (12 letters and digits; for example, file:///C:/Users/me/Downloads/1.0.3.html becomes a value like file.3c5e9a0d21b7). The file name and the folder path (such as C:/Users/…, which may contain your user name) are never sent. In this browser a file with the same name always gives the same value, so its glossary and translations are reused. On another computer, or after reinstalling the extension, the same file is treated as a new site. The file name is used only inside your browser, to show it in the popup. If you picked a website under [Same game as] in the popup, or the file's page title matches a web page you translated, the file is sent under that website's name instead of the hash so that its translations and glossary are reused. Which file is linked to which site stays in your browser. This is how it works from extension version 0.2.2 (test builds up to 0.2.1, which were never released on the store, sent the file name itself as the site name).
  • (Chrome extension) First visit to a site: part of the visible text (up to 120 pieces, 6,000 characters) and the page title, to detect the text kind, genre and style, write a short summary and propose glossary terms for proper names.
  • (Chrome extension) Image translation: when you turn on [Translate text in images] or [Keep translating images], or when scroll translation is on for a comic page, a screenshot is taken and only the image or canvas area is cropped, downscaled (longest side 1,568px) and sent. The whole screen is never sent. [Keep translating images] compares screen changes only on your computer and sends only areas that changed. Image translation never crops and sends frames (iframes) that it recognizes, by their address or name, as payment, sign-in or human-verification (CAPTCHA) windows from other companies. Scroll translation never crops and sends frames from other sites, and [Keep translating images] crops and sends a frame from another site only if it covers 40% or more of the screen (a game window). [Keep translating images] and scroll translation do not capture the screen while a password or payment field is visible.
  • (Chrome extension) Removing the extension: when you remove the extension, Chrome opens a Cozirom survey page (api.cozirom.com/bye). Only the extension version and interface language are added to its address, never an account number. You do not have to answer; the "uninstall survey answers" in section 2 are sent only if you press Send. The welcome page that opens when you first install the extension sends nothing (signing in from that page works like the sign-in in section 2).

4. What is public in the channel

  • Translations are posted in the channel under the writer's name and picture. They are not removed by a deletion request; the writer can remove them at any time with message right-click → Apps → "Delete my translation". This works even if the bot's webhook has been deleted from the server: the bot then deletes its own message directly. To recognize the writer, the 🔎 button on a translated message carries the writer's Discord user ID. It isn't shown on screen, but it is part of the message data, so Discord apps and other bots that can read the channel can see it.
  • By default, the original is posted in small text under each translation (only the beginning of long messages). It is part of the translated message, so anyone in the channel can see it as long as that message exists, regardless of the 14-day retention in section 2 or a deletion request. You can turn it off per server in settings (/translate setup); it then applies to translations posted after that. As above, the writer can delete those translated messages at any time with "Delete my translation".
  • The 🔎 button on a translated message lets anyone in the channel see the full original and its writer for 14 days (shown only to the person who pressed it).
  • With auto-translation on, a message with only images and no text is also posted again under the writer's name and picture (the images are not translated and stay as they are). Messages with images get image icons that anyone in the channel can press to see a translation of the text in the images (shown only to the person who pressed it, and counted against that person's translations).
  • Translation rooms: a room is a private thread the bot makes under a chat channel. Besides the people invited and those who joined, server admins and people with the Manage Threads permission can see every room, under Discord's rules for private threads. Translations in a room are posted under the writer's name and picture as in channels, and in rooms the original is always shown with them (in small text under the translation when two people joined, or first with the translation below it when three or more joined). When someone who hasn't joined writes in a room for the first time, a notice with their name is posted once in the room saying that their messages aren't translated or sent.
  • Language channels: messages in a channel a server admin turned this on for are copied, translated, into a channel the bot made for each language, under the writer's name and picture (as they are if already in that language). Language channels follow the original channel's view permissions: when the original channel's permissions change the bot matches them, and if someone who can't see the original channel could see a language channel, nothing is copied there. Copies mention nobody, and a copy of a reply says whom it answers in one line. Attachments aren't posted again; there is a link to the message that has them instead (the reposted translation, if auto-translation deleted the original). To edit the copies when the original is edited and delete them when it is deleted, the message IDs of the original and its copies are kept for 14 days (a server record with no text and no people in it, deleted when the bot leaves that server).

5. Logs

Operating logs keep only user IDs, counts, and the type and location of errors. No conversation content (the translation records and translation reports in section 2 are database records kept only for the periods in section 2, not logs). When a deletion is processed, the user ID and the number of deleted rows are logged. Operating logs are kept for 7 days on the bot server (Amazon Web Services) and then deleted.

When you use the payment and refund web pages (pay.cozirom.com), the access log of the server in front keeps the time, the address that connected (only the first two groups of the IP address are kept; the rest is masked) and the page requested. Browser details and cookies aren't logged, and one-time values carried in the address, such as sign-in codes and payment confirmation values, are removed. This access log is kept for 7 days and then deleted. No conversation content is logged.

(Chrome extension) The front-end access log of the web translation server (api.cozirom.com) records the time, the requesting address (only the first two groups of the IP address are kept; the rest is masked) and the requested path. The site name inside the requested path is removed. Browser information, extension version, sign-in tokens and cookies are not recorded. It is kept for 7 days and then deleted. The web translation server's operating log records the site domain, the number of items sent, the cost, and number-only cost statistics (how many sent items were on screen, off screen or hidden, and how many pre-translated items later appeared on screen), never the text. This operating log is also kept for 7 days and then deleted.

(Chrome extension) The front-end access log of the uninstall survey page (api.cozirom.com/bye) follows the same rule as the web translation server above (only the first two groups of the IP address, 7 days), and survey answers are not linked to that log. The extension version and interface language added to the survey page's address are removed from the access log. The survey accepts only a few answers per hour from the same place; to count them, IP addresses are turned into irreversible fingerprints with a secret value made anew each time the server starts, kept only in server memory for one hour (never stored).

(Chrome extension) Abuse prevention: to count whether too many requests come from one place, the web translation server keeps IP addresses only in server memory for one minute, as irreversible fingerprints. They are not stored and are discarded after one minute.

7. Content we don't translate

In Discord translations other than file translation (message translations, right-click translation, images, voice, language channels and translation rooms), sexually explicit content is not translated, under the translation model's usage policy. If the model declines, the original is left as is and nothing is counted. If that happens several times in one channel on the same day, that channel's messages are not sent to the translation model for the rest of the day. Messages in age-restricted channels are translated like any other channel. Images in age-restricted channels are not translated (they are not sent to the translation model), and language channels and translation rooms aren't available in age-restricted channels. Voice messages are transcribed and translated only in age-restricted channels, when someone on a paid plan presses [Transcribe and translate], and voice-channel reading reads only in age-restricted voice channels. Sexually explicit content is not translated or read there either.

File translation (applies once file translation opens) delivers its result in a message only the person who requested it can see. Because it translates the text of a file the user chose, adult content in novels and similar works is translated without toning it down. Sexual content involving minors, or characters who appear to be minors, is never translated. If the translation model refuses under its usage policy, the rest of the text is not sent and stays in the original. Files in age-restricted channels are not translated. Users are responsible for where they share the results (user responsibilities in section 9 of the terms of service).

(Chrome extension) The web extension translates the pages you choose as written, including mature content in games and fiction, without softening it (unlike the bot; sexual content involving minors is never translated). Lines the translation model refuses under its usage policy are left in the original (the cost of a refused request still counts toward usage).
